## ASCENDANT — The 100th Spire

A self-contained browser RPG. Open `index.html` in a browser (or serve this folder with any static web server) to play. Progress saves automatically in local storage.

### Controls

- **F** or **Enter** — strike
- **Q** — Arcane Burst (costs 12 mana)
- **Space** — evade a guardian's telegraphed attack
- **R** — drink a healing potion
- The on-screen buttons also work with touch and mouse.

Defeat each floor guardian to ascend. Every tenth floor is a boss; every fifth floor can award a stronger sword. Earn XP to level up and receive stat points, then tap **+ Stat Points** to invest. Reach and defeat the guardian on Floor 100 to win.
