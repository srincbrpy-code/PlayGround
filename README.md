# PlayGround

## POWER — a stickman duel

A minimalist 2D fighting game. Two stickmen, one line, no mercy. Best of three
rounds against a deliberately punishing CPU duelist.

- **Light / heavy strikes**, guard, parry, jump, and dash.
- **POWER** builds as you fight. At full charge, unleash a red-hot overdrive:
  extra damage, extra speed, afterimages, and a close-range shockwave.
- **Parry timing**: tap guard just before impact to stun the rival and steal
  the momentum. Holding guard only blocks (and heavy strikes chip through it).
- Responsive touch controls for phones and tablets, plus full keyboard support.
- Procedural sound, no external assets beyond the two bundled fonts.

### Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Move | `A` / `D` or arrows | Left stick |
| Jump | `W` / `Space` | `JUMP` |
| Light strike | `J` | `STRIKE` |
| Heavy strike | `K` | `HEAVY` |
| Guard / parry | `L` (hold to block) | `GUARD` |
| Power | `Q` | `POWER` |
| Dash | `Shift` | Double-tap the stick |
| Mute | `M` | `SFX` in the HUD |

### Run

```bash
PORT=3002 ./start.sh
```

The project is a static site: `index.html`, `styles.css`, `js/`, and `fonts/`.
